# SNS動画の内容分析

Claude Code は動画ファイルを直接読めない。`tools/sns-video/` のスクリプトで
フレーム画像と文字起こしテキストに変換してから読む。

## 手順

### 1. 素材が揃っているか確認する

`analysis/<動画名>/` に `frames/`, `transcript.txt`, `meta.json` があるか見る。
無ければ動画から作る。

```bash
tools/sns-video/ingest.sh <動画ファイル>              # カットの多い動画は -s を付ける
tools/sns-video/transcribe.sh analysis/<名前>/audio.wav
```

`ffmpeg` が無ければユーザーに `brew install ffmpeg` を案内して止まる。
文字起こしバックエンドが無い場合、音声は諦めて映像だけで進めてよい（その旨を明記する）。

### 2. 読む順番

1. `meta.json` と `frames/index.md` … 尺・解像度・フレームと再生位置の対応
2. `contact-sheet-*.jpg` … 全体の流れ・カット割りのテンポを把握
3. `frames/frame_*.jpg` … **冒頭2〜3秒は必ず全フレーム読む**。残りは変化点を中心に
4. `transcript.srt` … 時刻付きなので、テロップと発話のズレを見るのに使う

トークンを節約するため、いきなり全フレームを読まない。
コンタクトシートで当たりを付け、必要な区間だけ個別フレームを読む。

### 3. 見るべき観点

- **冒頭2秒のフック** — 最初の画面に何が映り、どんな文字が出ているか。短尺は離脱の大半がここ
- **テロップ** — 画面に焼き込まれた文字を時系列で書き起こす。フォント・配置・出し方（1行ずつ／一気に）も
- **音声との関係** — テロップが発話の要約か、別情報か、無音前提の設計か
- **構成** — 導入 → 展開 → オチ／CTA の時間配分を秒数で
- **画作り** — 被写体、寄り引き、カットの平均尺、色味
- **CTA** — 最後に何を求めているか（フォロー／保存／コメント／リンク）

### 4. 出力

`analysis/<動画名>/NOTES.md` のテンプレートを埋める。
数値（再生数・保存数など）はユーザーしか持っていないので、
空欄なら埋めずに「この欄は数値を入れてもらえると仮説の精度が上がる」と伝える。

## 守ること

- **見えたものと推測を区別する**。フレームに映っていない情報を断定しない。
  テロップが読み取れなければ「frame_012 のテロップは解像度不足で判読できない。
  `-w 1080` で再抽出すれば読める」と書く
- **数値の裏付けなく「伸びた理由」を断定しない**。仮説として書き、検証方法を添える
- 分析対象が他人の投稿なら、**構成やパターンの学習まで**に留める。
  台本やテロップの丸写しを生成しない
- 動画・フレーム画像はリポジトリにコミットしない（`.gitignore` 済み）。残すのは Markdown だけ

## 複数動画を比較するとき

`analysis/*/NOTES.md` を横断で読み、共通点を探す。
比較表（尺・フック種別・テロップ量・CTA・数値）を1枚作ってから考察を書くと、
印象論になりにくい。
